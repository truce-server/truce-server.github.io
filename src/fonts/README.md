# Fonts

All three families are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org) and are
served from here, so the site makes no request to a font service.

- **Libre Franklin** (variable weight 100 to 900). Copyright 2020 The Libre Franklin Project Authors
  (https://github.com/impallari/Libre-Franklin).
- **Source Serif 4** (variable weight 200 to 900, optical size 8 to 60). Copyright 2014 to 2023 Adobe
  (https://github.com/adobe-fonts/source-serif).
- **Cinzel** (variable weight 400 to 900), for titles and names on the Patrons pages only. Copyright 2020
  The Cinzel Project Authors (https://github.com/NDISCOVER/Cinzel). The files are the Fontsource builds
  (`@fontsource-variable/cinzel` 5.3.0).

Each family has two files: `latin` covers English and Western European text, `latin-ext` covers the
rest of the Latin alphabet. Anything else (emoji, symbols in chat names) uses the visitor's own fonts.
